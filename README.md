## 📌 Featured projects

### [YOLO RAG Agent](https://github.com/Pranav24112004/yolo-rag-agent)
A research assistant that answers questions about the YOLO paper series. Papers are parsed, chunked (text, tables, figures), embedded and indexed; a LangGraph agent classifies the query, retrieves with hybrid search, grades the results and generates cited answers.
`LangGraph` `Azure OpenAI` `Azure AI Search` `Cosmos DB` `FastAPI` `Streamlit` `RAGAS`
> Evaluated with RAGAS on a 15-question eval set. Needs Azure resources to run (see the README).

### [Presales Proposal Agent](https://github.com/Pranav24112004/presales-agent)
A multi-agent system that drafts proposal sections from past proposals, with a planner coordinating specialised agents and a human approval step. This is a personal reimplementation on an open-source stack, built for learning.
`ChromaDB` `Mistral` `Groq` `Python`
